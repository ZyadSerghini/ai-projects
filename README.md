## 🏠 KB Smart Home

A real-time rule-based smart home AI system built on a knowledge base, simulating multi-room environments and evaluating conditions like motion, temperature, lighting, and occupancy to autonomously control devices using symbolic reasoning and dynamic heuristics, implemented in Python.

## 🛒 KNN Shopping Model

A machine learning–based shopping behavior prediction system that processes real-world browsing data, transforms it into structured features, and uses a K-Nearest Neighbors (KNN) model to classify user purchase intent while evaluating performance through sensitivity and specificity metrics, implemented in Python using the scikit-learn library.

## 📜 Syntax Sense Parser

A rule-based natural language parsing system that uses a context-free grammar (CFG) to analyze sentence structure, generate parse trees, and extract noun phrase chunks, leveraging the Natural Language Toolkit (NLTK) for tokenization and chart parsing, implemented in Python.
